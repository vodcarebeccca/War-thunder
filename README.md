# WT Market

A Vercel-ready static storefront concept for a War Thunder account marketplace.

## Deploy on Vercel

Import this repository into Vercel. No build command, framework preset, database, or environment variables are required for this preview. Vercel will serve `index.html` directly.

## Current scope

- Responsive storefront landing page
- Account listing cards
- Client-side category filters
- Shortlist/cart preview interaction
- IDR and USD display
- No real checkout, credentials, admin panel, or payment integration yet

The site is an independent concept and is not affiliated with Gaijin. Verify marketplace and payment-provider terms before enabling sales.
