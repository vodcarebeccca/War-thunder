# WT Market

Static Vercel preview matching the original WT Market visual direction: dark neon UI, orange accent, blue glow, grid background, bilingual navigation, feature cards, catalog filters, stock badges, IDR/USD pricing, and legal notice.

Import this repository into Vercel. No build command or environment variables are needed for this preview.

This is the visual storefront layer. Real checkout, admin, stock, and Midtrans still belong in the full Next.js app once a persistent database is configured.
